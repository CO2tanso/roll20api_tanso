# change_profile.js
롤20에서 프로필사진 변경을 가능하게 해주는 api입니다.
<br>**개선이 불가한 오류가 있으니 하단 주의사항을 반드시 확인한 후 사용해 주시길 바랍니다.**
<br><br>저장소 많이 잡아먹습니다...
<br>저장소에서 표정 이미지들을 삭제하면 **로그에서도 이미지가 함께 사라지니** 유의해 주세요.
(때문에 사실 여러번 사용할 고정 캐릭터나 용량이 넉넉한 구독제 사용자가 아니라면 비추합니다...)
<br>
## 사용법
<h3>표정 세팅</h3>
등록하려는 표정 이미지를 하나씩 저널 아바타에 넣고 차례로 이미지 주소를 복사합니다. (하단 이미지 참고)

<br><img width="600" height="385" alt="image" src="https://github.com/user-attachments/assets/7a881f3f-d810-45b4-9f09-a515c468ebf5" />

<br><br>그대로 저널 편집 스크롤을 내리면 **개요 및 정보**란이 있습니다.
<br>하나씩 `표정명(이미지링크)` 형식으로 한줄씩 넣고 저장하면 세팅이 완료됩니다.<br>
<img width="782" height="549" alt="image" src="https://github.com/user-attachments/assets/dd853ee8-fa57-4117-822e-1898b06869d1" />
<br><br>

<h3>표정 변경</h3>

채팅의 명령어 `!@표정명` 으로 작동합니다.
<br>**일반 채팅과 함께 사용 불가능 합니다!** 반드시 `!@` 문자로 시작해야만 api가 발동합니다.
<br><br>

## 주의사항
롤20의 기능을 어떻게든 비틀어 사용하는 것에 가깝기 때문에 일부 오류가 있습니다. 확인 후 괜찮은 분들만 사용해 주세요.

<h3>1. 유령채팅</h3>

<img width="744" height="409" alt="image" src="https://github.com/user-attachments/assets/3d950a1e-a0f1-4cf1-a053-b04c1e08b642" />
<br>사진과 같이 api를 이용하면 작은 유령채팅이 이어붙습니다.
<br>표정 변경을 연달아 사용시, 로그에 캐릭터 이미지 변경이 정상적으로 기록되지 않기 때문에 의도적으로 넣은 desc입니다. 수정하지 않는 것을 추천드립니다..

<h3>2. 시트 재입력</h3>

시트에 입력한 내용의 전체 자동 재입력 현상이 불규칙적으로 일어납니다.
<br>데이터가 사라지는 것은 아니지만, **자동화 시트 작동 후 2차로 작성해야하는 내용이 있다면 그 부분을 재입력 해야합니다**
<br>또한 캐릭터의 스테이터스 변경에 반응해 작동하는 api가 있다면 해당 api도 작동하게 됩니다.
<br> (예: 마기카로기아 세션에서 주로 쓰이는 양천일님의 attribute_tracker api)
<br><br>저의 경우, 해당 문제의 방지하기 위해 PC용 저널을 프로필용/시트용 두개씩 배분하고 있습니다.

<hr>

코드 시작부의 `use_sheet`를 `true`로 변경하면 시트 내부 메모란을 표정 기입란으로 사용 가능해 집니다. <br>
<br><img width="452" height="572" alt="image" src="https://github.com/user-attachments/assets/74e52507-d453-4280-98b4-6b3a3fd622bb" />

<br>다만, 기본적으로는 `<textarea name="attr_memo">` 태그를 기준으로 작성되어 있으며 사용하는 시트의 메모란 태그 name이 다르다면 작동하지 않습니다.
<br>커스텀 시트를 사용하는 경우, 표정 기입란으로 사용하려는 태그의 name을 찾아 `tag_name`을 해당 name으로 수정해 주세요. (attr_ 은 지우고 넣습니다.)
<br>본문 대로 '개요 및 정보'를 사용한다면 코드 변경 없이 사용하면 됩니다.
